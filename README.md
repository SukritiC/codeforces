# DSA & Competitive Programming Practice

This repository serves as a personal collection of my solutions to various Data Structures and Algorithms (DSA) problems from platforms like Take U Forward, Codeforces, and other online judges. It's a space for practice, learning, and refining problem-solving skills in Python.

## 📂 Repository Structure

## 🚀 Getting Started

### Prerequisites

Make sure you have Python 3.x installed on your system.

### Usage

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/SukritiC/codeforces.git
    cd codeforces
    ```
2.  **Navigate and run a solution:**
    You can run any solution file directly to see its implementation. Most files are structured with a `Solution` class, designed for platforms like LeetCode.
    ```sh
    # Example
    python3 DP/1D/climbing_stairs.py
    ```
